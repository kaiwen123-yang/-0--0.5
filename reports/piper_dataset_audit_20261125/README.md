### A · 单臂积木入盒

发布方将机器人标为 Piper，七维顺序为 J1–J6、gripper。外部和夹爪两路为 640×480 RGB。200 条只有一条通用抓放指令，没有按颜色选择的语言监督。实拍样本中除了黄色长条积木，还有绿色积木，箱体为纸盒。腕图能看见黑色双指夹近积木、搬运和盒口，但部分起始位置在画外。152 号的外部全帧序列显示，人手在约 20–70 帧摆入绿块并整理盒内物体。后段机械臂运绿块到盒口，750 帧结尾未见明确的释放后撤离。0、100、199 的取样图可见盒中积木。不同终态需逐条判断。

状态夹爪数值为 0.00007 至 0.06874，动作夹爪为 −0.00168 至 0.07308，150,107 行中有 59,413 个负目标。发布字段没有确证零位、极性、单位和指尖物理宽度，也缺少采集代码或控制回执。变化关节中，action[t] 与 state[t+k] 在 k=+2 时平均绝对差最小。同帧和下一帧整向量精确相等均为零。这个结果与目标先于机械响应相容，单凭它不能认定目标来自主臂或已下发。时间列符合 frame_index/30，未取得逐设备原始采集钟。数据卡标 Apache-2.0。[固定数据卡](https://huggingface.co/datasets/DRMNmadhan/piper_pickdrop_200/blob/867554b0b60c78d779e048203acb28e19fab650b/README.md)

### C · 四色积木分类

120 条、27,903 行、两路 256×256 RGB。12 种积木色与盒色组合中，8 种各 8 条，4 种各 14 条。实际字段名为 state 和 actions。逐回合任务编号、颜色文本和长度均匹配转换说明。视觉抽检覆盖全部 12 种组合。同一颜色组合有不同盒位，31 号还从深色圆形容器内夹出绿色积木。腕图近距离能辨色并看见夹指，移向盒口时视野往往只剩目标盒，部分末帧被盒壁或夹指遮挡。固定机位提供独立的颜色与容器参照。逐样本的可见性和不确定项见[视觉审阅记录](visual_review.csv)。

发布方说明 state 是实测反馈，actions 为同帧发布的绝对目标，六关节 rad，夹爪总宽 m。动作夹爪范围 0–0.0700 m，实测开口 0.0316–0.1002 m，显示两路不是同一份测量。以变化关节聚合，误差由同帧 0.03374 rad 降至 k=+3 的 0.00807 rad，独立的原 CSV、发送时间和曝光时间未随版发布。不能将跟随延迟解释为应把动作平移三帧。使用者应区分其命令标签与本机 50 条未来反馈标签。

发布名为 Piper，info 写 piper_standard，转换说明保留含 piperx 的旧 repo_id。缺少足以区分标准型、X 或 H 的硬件标识。此版本 README、仓库树及卡片元数据均未见明确数据许可，只作本地审查。未上传原始数组、视频或帧图。[固定转换说明](https://huggingface.co/datasets/tianxiwei/piper-four-color-block-sorting/blob/8d5ee5d2a44dfe1798489d13c1fc0bdd168be12e/conversion_notes.json)

### D · openpi_lab 的 Piper 部分

四项任务依次为笔入杯 30 条、胡萝卜入碗 33 条、积木入第二个抽屉并关好 32 条、三个碗叠放 30 条。实拍中同一只夹爪和腕图覆盖接近、夹持与搬运。抽屉和叠碗需要多个物体及容器状态，近距离的 hand 画面容易被抽屉面或相邻碗遮住。125 条均有 head 和 hand 视频。附加 CoT Parquet 的 71,702 个 episode/frame 键与主表一一对应，77 号第 111–114 行的两项夹爪投影坐标为负，原腕图仍可读。投影字段的缺项没有扩展到关节或动作。

仓库 README 在服务接口部分将六关节输出描述为“相对回合起始姿态”，夹爪为绝对量，同时将 Piper 的 action 解释为记录的遥操作目标。**不能据此对原 Parquet 再加一遍起始角度。** 125 条的第零行状态和动作均没有全零六关节向量。原六轴状态和动作均值更接近发布的 norm_stats，两者最大逐轴差分别约 0.00039 和 0.00118。若先逐回合减首个实测六轴，分别变为 0.03454 和 0.03536。文件另有标记 joint_delta 的 GR00T 统计，拥有不同用途。变化关节在 +3 行时的误差最小，与发布者描述相符。证据支持 Parquet 保留位置/遥操作目标坐标，公开内容没有明确交代其物理零位或训练在哪一层减去了哪一个起点。发布仓库不含所指 Piper 服务/客户端脚本，按入口与数据名检索公开代码也未定位到匹配实现。

若后续确认得到相对输出，恢复绝对关节目标需要同一回合、同一关节顺序和坐标零位下的实际参考 q₀，按发布定义将输出的六轴偏移与 q₀ 相加，夹爪维保留其独立绝对量。必须先确认 q₀ 来自重置参考、采集起点还是首个保留的观测。同帧状态、逐步增量、首个动作和回合起点是不同参考。未作数值改写。[固定发布说明](https://huggingface.co/siyuhsu/openpi_lab/blob/c2e5619878c2bf2188e6d04d727deee605fdd1e2/README.md) · [原值与参考假设的统计](D_representation.json)
