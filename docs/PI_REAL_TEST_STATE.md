## 当前工作顺序

1. 当前选择新批次重采。先待现场操作者核实越界原因、支撑/净空与恢复，再读取本机实际关节及范围。可靠固定时允许静止检查棋盘画面；新固定板手眼采集要求整板和物理原点可辨。
2. 新批训练/留出事先分组，保留全部原图索引、有序 88 点、真实 G/q、时间和筛选来源，维持最低 15/5。一次届时仅用训练组拟合五项基线与 CALIB_FIX_K3，分别重求 PnP/Park/训练参考。模型选择与最终独立验证分开，另留约 8 个新验证姿态。
3. 现场用尺度表补长短向格距与外板尺寸。实际任务距离、较大侧向基线及安全可见的下部仍待覆盖。如改为机械臂固定、仅移动棋盘，独立采 intrinsics_only，不进入固定板手眼姿态集。
4. 旧 27+4+3 作为原安装历史基线。仅当以后找回原始输入时，才可按同一角点表解释为原 27 组重拟合；新批不得写成旧试验复现。
5. **并行π数据线：**继续原始单腕RGB和RoboMIND语义适配，分别计算两个模型的norm；不把无动作静止观测变成示范，也不把标定完成等同模型可直接运动。

每次实质工作结束必须按北京时间更新唯一 [PI_DAILY_WORK_LOG.md](PI_DAILY_WORK_LOG.md)，同一天按会话追加目标、实际操作、问题与修复、真实验证、剩余项、硬件最后状态和证据版本。日志的详细格式和更正规则见AGENTS。
