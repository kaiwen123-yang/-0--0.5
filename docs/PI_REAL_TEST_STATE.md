## 当前执行顺序

1. 现场按指南运行 `camera`、`view`、`status` 和 `prepare`，核对开口后运行 `teach`。按实体键进入/退出示教，键盘 C/O/E 加回车记录两处意图和结束。
2. 完成真实路径的低速空场检查，再用轻质物体放浅盘取得 3–5 条成功记录，验证动态时间、开合和完整动作来源。初始检查默认 commissioning_only。
3. 扩大正式本地示范到约 30–50 条有差异的完整成功 episode。50 条可按源路径/布局/会话分为 40 train / 10 validation；不是帧随机切分，也不是保证效果的最低量。
4. 转换可追溯 20 Hz 数据、计算各自 train-only norm、填写正式训练预算后分别全参微调。使用同一数据划分，保留两模型不同基础权重和资产。
5. 实际微调模型先做真实观测推理核查，再验收现场在线动作调度，最后按冻结条件做 π0 / π0.5 初步实机比较。公共候选后续可成为独立迁移/消融实验，不阻塞当前主线。
