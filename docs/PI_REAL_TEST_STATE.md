## 当前工作顺序

1. 从原机或只读副本取回原审阅 manifest 和实际拟合角点表。按已冻结规则对同一 27 训练组比较 flags=0 与 CALIB_FIX_K3，各自重求 PnP、Park X、训练参考和全链/全幅评估；旧验证参与选择后转开发验证。已有五图与整幅基线结果见 11/22 记录。
2. **现场测量另补：**复核板十格/短向格距/外板尺寸及量具口径。197mm仍为粗读；不假造精测，不直接缩放旧X。
3. **后续动作前独立处理：**重新只读读取状态，核实净空/接触/安装，由适用厂家流程和现场操作恢复；复核到位标志与超时停止策略。当前离线任务不自动使能、回零、改限位或发姿态。
4. **有条件后新验证：**冻结候选与规则后采真正新预留姿态，覆盖下部、任务距离与更大侧向基线。必要时另采intrinsics_only覆盖图，不能混入固定板手眼集。
5. **并行π数据线：**继续原始单腕RGB和RoboMIND语义适配，分别计算两个模型的norm；不把无动作静止观测变成示范，也不把标定完成等同模型可直接运动。

每次实质工作结束必须按北京时间更新唯一 [PI_DAILY_WORK_LOG.md](PI_DAILY_WORK_LOG.md)，同一天按会话追加目标、实际操作、问题与修复、真实验证、剩余项、硬件最后状态和证据版本。日志的详细格式和更正规则见AGENTS。
