# π0 下一步：先修复自主目标选择，再扩展训练

2026-11-01。**这是依据已完成诊断形成的下一步方案，尚未启动新训练。** 详见 [分析报告](PI0_120_REGRESSION_ANALYSIS_20261101.md)。当前 120 条训练保持在 8,040 次，保留原检查点及其全部失败结果。

## 目标与依据

首先恢复“看到同一场景，能按红/绿/蓝指令选择不同接近目标”的能力。旧模型同环境验证 11/30，新 8040 为 2/30；同观测同噪声的初始教师末端匹配分别为 26/30 和 10/30。对十个退化试验纠正最初 1.5 s 后，新模型能完成 8/10，纠正到下降末段后为 10/10。当前优先问题是自主前段目标选择，暂不以调整摩擦、增加恢复示教或修改成功判据作为主线。

## 第一优先：从已具备指令响应的旧模型出发，比较两种采样

建议建立两个独立新 run，均从旧六示教 2010 完整检查点初始化，并保留该检查点的优化器状态、RNG 和原归一化。这是新的适应实验，不接着改写旧六示教结果，也不把它算作原 120 条从 base 训练的延续。

选择旧模型是为了保留已经观察到的指令响应。它在冻结 v2 下已有 5/15、6/15 的基线。两组都使用新 v2 的 120 条原始训练示教，但使用相同的旧训练归一化，使初始化时的观测/动作尺度保持一致；不计算验证或测试统计。

| 项目 | A：均匀采样对照 | B：前段采样加权 |
|---|---|---|
| 初始化与优化器 | 同一旧 2010 完整状态 | 相同 |
| 归一化 | 旧六示教训练资产，冻结 | 相同 |
| 数据、物理、相机 | 原样使用已冻结 v2 的 120 条 | 相同 |
| 模型与冻结策略 | 现有配置，不改视觉编码器冻结 | 相同 |
| batch / horizon / 执行动作数 | 4 / 10 / 5 | 相同 |
| 新增更新预算 | 最多 2,010 次 | 最多 2,010 次 |
| 学习率 | 固定 3e-6，无新增 warmup | 相同 |
| 采样 | 所有 32,160 起点均匀抽样 | 40% 来自帧 0–9；30% 来自帧 10–61；30% 来自帧 62–267 |
| 颜色抽样 | 三种颜色等概率 | 三种颜色等概率 |
| 随机性 | seed 42；预先保存采样表与每次 RNG 规则 | 相同约定，采样表独立保存 |

两组之间只比较采样分布。warm start、较低学习率和保留旧归一化是两组共同的工程选择；若它们优于原 120 条实验，不能把改善全部归到其中某一个选择。原优化器计数继续记录，同时新增本 run 的局部更新数和新采样偏移，不混用旧 2,010 的采样位置。对该 fork 的配置变化单独声明，不能冒充配置完全不变的恢复。

前段加权只改变现有数据被抽到的频率，不将重复抽样算作新增示教。保持颜色均衡，也不同时引入成组三色批次、新图像增强、损失权重、视觉冻结或新的恢复数据，以便判断采样本身是否有效。

## 评测与停止规则

在新增 500、1,000、2,010 次处顺序停止训练并评测：原六项训练诊断 × 两种子，以及 15 项验证 × 两种子；使用当前完全相同的 seed、环境、执行上限和完整成功标准。每个节点补做冻结输入的提示词置换，报告五个布局分组结果。

主要指标是两种子的完整任务成功。辅助指标是闭爪时目标身份、目标水平误差、非目标抬升、初始指令对应教师末端匹配，以及下降/抓取阶段的固定观测动作误差。

预先建议的工程推进门槛：

1. 初始教师末端匹配至少 24/30，且不同指令不再普遍落到同一个教师末端。
2. 闭爪时最近物体为正确目标至少 24/30，非目标抬升不超过 2/30。
3. 完整验证合计至少 11/30，两个种子各不少于 5/15；两套结果全部报告，不仅保留更好一次。
4. 没有数值、动作或评测执行错误，逐次日志、检查点和发布记录完整。

这些阈值用于决定是否值得扩大预算，不构成统计显著性或实机资格。若两个训练节点出现指令末端匹配持续下降，即使 loss 降低，也先停下检查；若截至 2,010 仍不能达到前段条件指标，则不自动延长到 16,080/24,120。

## 结果将如何改变下一步

- **A、B 都保持指令响应并改善完整成功：** 先保留更稳定的验证候选，说明 warm start 与共同的适应设置可行；还不能独立归因于学习率。之后再增加训练种子检查稳定性。
- **B 明显优于 A：** 支持初始选择阶段的训练权重不足这一解释；再在相同配置下扩大 B 的预算，而不是立即增加更多正常示教。
- **两组都能选对目标，但抓取仍失败：** 才优先增加具体对准偏差、边缘夹持和未夹住状态的教师纠正轨迹，保持恢复比例单独可控。
- **两组都再次失去指令响应：** 下一组只改变视觉/语言相关参数冻结或学习率中的一个因素；对照组继续保持其余条件不变，并以初始条件动作指标诊断。

若最终需要严格回答“6 条与 120 条哪一种更有利”，另做从同一 `pi0_base` 初始化、同一 v2、同一归一化标尺、同一学习率时间轴和相同更新预算的数据量对照；再单独比较相同起点遍历次数的预算。它属于归因实验，不与上述工程修复结果混为同一结论。

## 资源与保存

两组顺序运行，避免同时加载两个大模型。按已有约 0.295 s/update，4,020 次新增更新的纯计算约 20 分钟；加上六组完整节点评测、模型切换、编译和保存，暂按 1.5–2 小时预留，并在启动后重新估计。此为预算估计，不是完成承诺。

开始前重新核对共享 GPU 和磁盘。完整检查点保留最近两个和所选候选，事先控制新增存储约 60 GiB 的上限；逐次指标和原始评测轨迹全部保留。继续在 tmux 中运行，每 500 次及每个评测节点推送；网络失败有界重试并保存待补传记录。

候选只依据验证选择。独立 30 项测试在配置和候选冻结后执行一次。本轮诊断没有开始上述训练，也没有使用测试集或执行硬件动作。
