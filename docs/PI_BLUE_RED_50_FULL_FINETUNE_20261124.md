## 3. 实际动作标签：采用手拖的未来实测位置

本批最终采用的合同为：

```text
collection_mode = kinesthetic_manual_gripper_v1
arm_action_source = future_measured_joint_positions
gripper_action_source = future_measured_sdk_width

state = 当前六关节实测位置(rad) + 当前 SDK 实测开口(m)
action = 未来 50 ms 对应的六关节实测位置(rad) + SDK 实测开口(m)
```

所有 50 条相邻行满足 actions[:-1] 与 state[1:] 逐元素一致，网格间隔严格为 50,000,000 ns。采集时主机 CAN 发送增量为 0；这意味着数据来自被动手拖和实测夹指运动，**不意味着没有训练标签**。位置模仿所用的未来目标明确从反馈重建，不能将它描述为历史真实发送的电控动作或已学得夹持力。

C/O 是操作者在实际抓住、实际放下后的事件标记。T01-FOUR02 蓝的 O 明显晚于图像中的释放；连续实测宽度是训练依据，不能把两个按键临时转换成固定开闭阶跃来替代真实标签。现场早先电控 C 没有成功闭合的失败尝试不属于本批最终成功合同。

单腕输入继续使用 DC1 CC16762023M，camera_mount=wrist，只有 left_wrist_0_rgb 有效；不增加第二视角，不改变原始 RGB 像素域。state/action 七个实际维度通过已有变换进入模型：前六轴做 delta，夹爪保持绝对 SDK 宽度，模型内部维度仍为 32，推理出口恢复七维绝对目标。

按全部行级来源复算的接收年龄：

| 通道 | P50 / ms | P95 / ms | 最大 / ms |
|---|---:|---:|---:|
| RGB | 16.770 | 31.891 | 47.426 |
| 六轴 | 3.892 | 4.875 | 11.346 |
| 夹爪 | 3.824 | 4.802 | 11.233 |

这些是同机接收时间关系，不是相机曝光同步或主动控制延迟的证明。

## 5. 必须在后续结果中关注的三类限制

### 5.1 SDK 开口范围与旧主动发送器不一致

旧主动发送器采用 15–40 mm 范围；本批有效训练动作覆盖约 0–99.7 mm，验证覆盖约 0–99.3 mm。对实际可采样 action chunks 的每一步计数（包含重叠窗口和末尾补齐）：

| 指标 | train | validation |
|---|---:|---:|
| 动作步次 | 211,630 | 54,060 |
| 超过旧 15–40 mm 范围的步次 | 114,106 | 28,591 |
| 比例 | 53.9177% | 52.8875% |

50 个抓住 C 的实测开口为 26.7–34.2 mm，47 个 O 的开口大于 40 mm。训练与验证开口 P95 分别约 65.5、92.5 mm，验证开口分布也更大。

**全参训练保留真实标签，不为了旧发送器把数据剪成 15–40 mm。** 上机前应依据官方接口及本机实际反馈，落实主动 SDK 宽度、夹持力设置与模型输出的对应关系。被人手带到某个反馈宽度，不自动等于给电机相同位置目标就会产生足够夹持力；数据没有可学习的真实力命令。

本次没有扩大控制器硬限位，也没有把手动 0–100 mm 有效域直接当成已经实测验收的主动全行程。训练可以先开展，执行合同衔接仍是上机前的具体任务。

### 5.2 起始覆盖和按语言选色还需要实际验证

41/50 条的首个有效窗口晚于 S，37 条超过 1 秒，中位延迟 2.425 秒，最长 7.7 秒。配对布局中，蓝红两条的起姿最大轴差中位约 8.97°，最大约 101.234°；24/25 对先蓝后红。

因此，这批数据包含真实抓放，却不能单凭“同布局蓝红配对”证明模型必须依赖语言、或完整覆盖“统一六轴零位→发现目标→接近”的全过程。配对图的第一列是 C 前约 2 秒，常已贴近物块，也不能替代起始腕图覆盖证据。

首轮先训练现有版本。部署评估要分别记录是否能从实际起点主动接近、是否选对颜色、是否夹住、是否放入盘和空爪抬离。安排新的实际摆放，蓝红换位置，在相同起始条件下切换蓝/红指令；最终成功率来自这些模型闭环尝试。不要把某个接近后片段的低误差写成任意位置自主抓取已成功。

### 5.3 静止多、部分手拖运动较快

以完整十步窗口内部“所有关节跨度≤0.5°且夹爪跨度≤1 mm”作描述性统计，本次得到 14,478 / 26,245，约 55.16% 为低运动窗口。原报告为 14,475，差 3 个阈值边缘窗口；目前未定位原计算次序，不能宣称描述性统计逐字完全重现。差异不影响有效起点、标签或 55.2% 的量级结论，不扩展为重新处理数据的任务。

有效训练行最大相邻 50 ms 关节差约 11.899°，最大十步目标相对输入 state 的单轴差约 87.024°，最大相邻夹爪差约 22.8 mm。它们描述手拖记录，不是主动机械臂跟踪能力的验收。后续使用模型闭环重新观察和更新目标，不能把半秒动作块原样整块开环执行就假定跟得上。

本轮不另加静止重采样、删静止或速度裁剪，以保留冻结数据和可解释的首轮基线；验证单独区分移动与低运动，并加入“保持当前状态”基线。

## 6. 正式全参训练方案

两模型使用同一冻结数据、各自基础权重和独立 train-only norm。原配置的全参路径有效：gemma_2b / gemma_300m 基础变体，freeze_filter=nnx.Nothing，不使用 LoRA。实际启动时读取 parameter_counts.json，记录全部参数数和可训练数；源码配置正确不能替代运行中的真实参数统计。

| 项目 | π0.5 | π0 |
|---|---|---|
| 顺序 | 第一项 | π0.5 训练及验证完成后 |
| 独立既有环境 | /root/autodl-tmp/robot-repro/pi05/activate.sh | /root/autodl-tmp/robot-repro/pi0/activate.sh |
| 基础权重 | pi05_base/params | pi0_base/params |
| state / norm | 离散状态、quantile | 连续状态、mean/std |
| 可训练参数 | 全部 | 全部 |
| batch size / workers | 8 / 4 | 8 / 4 |
| 步数 | 10,000 | 10,000 |
| 学习率 | 500 步 warmup，峰值 1e-5，余弦衰减到 1e-6 | 同左 |
| action horizon / policy grid | 10 / 20 Hz | 同左 |
| seed / EMA | 42 / 关闭 | 同左 |
| 常规 checkpoint 间隔 | 1,000 步 | 1,000 步 |
| 长期保留周期 | 5,000 步，并保留最后一次 | 同左 |

模型、optimizer 和 train_state 都由官方 checkpoint 机制保存。run_spec 保存种子、配置、路径及本批数据合同。不声称完成了逐比特恢复验证或额外保存了 DataLoader 随机游标。

10,000×8=80,000 次训练起点取样，约为 21,163 个 train 起点的 3.78 倍。这是首轮正式预算；数据高度重叠，不能把它说成 80,000 个独立示范或达到该步数就保证成功。正式运行稳定后的实际 step/s 用于 ETA，不新增容量试跑，也不保证某个时刻训练完成。

### 本次修正了哪些准备问题

1. 两份 pickplace_*_full.json 的默认数据路径改成已上传的 blue_red_direct_20261124_50_v1，实验名改成 dc1_wrist_blue_red50_full_20261124_v1，记录手拖未来实测动作来源。

## 7. 独立验证怎样判断训练是否有用

新增入口对 V01 每条按有效起点顺序均匀取 64 个窗口，共 640 个。固定 seed=20261124，并以 episode/frame 固定流模型采样噪声；不同 checkpoint、两模型使用同一批真实观测。每个模型只用自身 checkpoint 中由 train 生成的 norm，validation 不进入统计或梯度。

输出整体、每色、逐条示范指标，并将各 episode 等权汇总：

- 六轴 MAE/RMSE（度），逐轴 MAE；
- 夹爪 MAE/RMSE（mm）；
- 第一步和最后一步误差；
- 移动段、低运动段分别统计；
- 相同样本上“保持当前七维状态”基线；
- 固定样本的来源、实际帧号、时间、补尾标记与完整预测。

评估的移动分组定义是“未来十步任意目标相对当前状态变化≥0.5°或夹爪≥1 mm”，不是前节窗口内部跨度统计，也不是新增运动限位。对真实 V01 的此次 640 个抽样，340 个移动、300 个低运动。[无模型参考](../results/pi-readiness/20261124/chat_audit/validation_sampling_reference.json)得到保持状态基线的 episode 宏平均关节 MAE 约 0.804704°、夹爪 MAE 约 1.898984 mm。**这是基线，不能写成 π 模型成绩。**

每个模型内按移动段、七个实际动作维度的 train-normalized MSE，选出保留 checkpoint 中的验证候选，同时保留蓝/红及夹爪物理误差供复核。两模型归一化不同，不能直接拿这项归一化分数给 π0/π0.5 跨模型排名；跨模型比较用相同物理单位指标和后续实际闭环表现。

V01 用于模型选择后属于 validation，不再冒称完全独立最终 test。离线预测误差不等于真实抓取成功率；保持基线已经说明总体小误差可能来自静止段。若移动段不优于保持基线，先看实际模型预测、优化曲线及错误阶段，决定训练调整或针对缺口补少量示范，不立即重复整批采集。
