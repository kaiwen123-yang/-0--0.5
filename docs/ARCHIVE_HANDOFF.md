## 实验结果的含义

原版 Panda/LIBERO 基线为 π0 183/200、π0.5 196/200。Piper H 适配扩展实验为 π0 32/75、π0.5 47/75。两者机械臂、协议和初始状态不同，不能跨实验直接归因。

颜色入盒 LoRA 完成 1500 步后验证为 0/15。10/15 轨迹曾把指定物体抬起超过 5 cm，但均未满足完整入盒与松爪条件，所以成功率仍是 0/15。全参数训练执行至 1456 步中断，没有最终评测。最后保存的目录 1000 对应内部 optimizer step 1001；该检查点本次不上传。

165 条教师示范全部通过的是教师数据质量检查；教师使用物体真值，这个数字不是学习策略的任务成功率。没有连接实机，也没有形成经实机验收的部署模型。

## AutoDL 中断记录与以后开跑前的检查

本次原实例保留了平台 22:00 定时关机。启动任务时只确认脚本没有 shutdown，漏查平台定时，导致全参数阶段中断。后续要同时确认平台的定时开关机与任务脚本；tmux 只能应对终端断连，不能阻止平台关机。

每次长任务应记录代码版本、依赖版本、数据划分、模型来源和输出盘位置；检查日志中确实出现 optimizer update，并确认首个可恢复检查点成功保存。根据可接受的重算时间设置保存间隔，不把进程还在、loss 下降或已有权重文件等同于训练完成与任务成功。

本次重启 GPU 实例遇到空闲 CPU 不足，随后用无卡模式读取文件。不要把关机后能立即恢复原资源当作已验证条件。长期或包月方案的资源保障、关机计费及存储保留规则，应在下次购买时单独核实。

## 取回与继续使用

README 给出了分卷恢复命令。`archives/manifest.json` 列出两个归档的逐文件路径和大小。`cloud/extra-results/` 保存补取的云端启动渲染及教师检查视频；`cloud/normalization/` 保存旧烟雾测试的归一化配置。训练时的原始任务源码包另存于 `archives/piper-color-original-source-v1.tar.gz`。

历史 HANDOFF 文档和日志按原样保留，其中可能出现已取消的后续计划；本交接与仓库首页描述最终实际状态。LoRA 推理参数在 fy-5080 本地已有完整副本，未上传 GitHub；全参数本地副本不完整，不能依靠它续训。
