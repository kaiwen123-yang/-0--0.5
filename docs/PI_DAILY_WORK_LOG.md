- 同日不同会话继续追加；修正注明原结论、原因和新证据，不覆盖历史。无可靠记录的日期不推断为没有工作。

- 区分准备、实际执行、部分完成、NOT_RUN、未证实、已停止；文件存在不代表模型运行或硬件验收。
- 测量、请求目标、实际提交和预测分开；无动作来源的观测不补写成示范。版本化保留原数据、标定和训练资产。
- 公开真实数据优先、零本地任务示范优先；先核实公共数据再训练，是否补采由实测决定。
- 硬件状态仅是带时间快照；下次现场重读，不据日志自动使能、回零或发模型动作。
- 文末固定证据链接与本文件 Git 历史共同追溯版本；大文件留原机器，Git 小文件发布不等于完整备份。
