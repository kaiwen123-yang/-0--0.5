- 区分准备、实际执行、部分完成、NOT_RUN、未证实、已停止；文件存在不代表模型运行或硬件验收。
- 测量、请求目标、实际提交和预测分开；无动作来源的观测不补写成示范。版本化保留原数据、标定和训练资产。
