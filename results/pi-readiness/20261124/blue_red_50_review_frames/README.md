# 50 条蓝红示范的分布局腕图索引

每张图对应一个实际布局。上排为抓蓝，下排为抓红。T01、T02 共 20 个训练布局，V01 为 5 个独立验证布局。每行均来自同一条单腕 RGB 原始记录。

从左到右依次取抓取标记前 2 秒（最早到任务起点）、C 标记、C 与 O 中间时刻、O 标记和 E 标记。各列使用相应时刻及之前最近的实际接收帧。每幅小图下方有目标颜色、原始 RGB 帧号和相对 S 的实测帧时间。原图尺寸为 640 × 480，联系表按原宽高比缩放。选帧聚焦桌面、浅盘和夹指。逐图查看了 250 个画面，未见可辨认旁人面部或可读的屏幕信息；部分画面包含进行手动夹指示教的手部。本索引所列帧号均按上述统一时刻选取。完整原始记录留在采集机。

C/O 由操作者报告已经发生的抓取和释放，可能晚于实际开合。例如 T01-FOUR02 蓝条的 O 时刻已抬离，该条真实入盘画面可见此前的第 750–900 帧及[补充画面](../blue_red_50_visual_examples.jpg)。抽帧可供复核目标颜色、盘外取物及空爪离开，单腕画面无法单独测定实际受力或排除帧间短暂接触。

表中源名是对应会话内的采集目录，可结合[逐条视觉回执](../blue_red_50_visual.json)定位源 ID 和其他抽查帧。
