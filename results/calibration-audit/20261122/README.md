## 为什么能判定 593 个接收像素没有中央分支逆解

用原生 K 归一化。对每个接收整数像素求完整 Brown 逆映射，检验正向回投和 Jacobian。306,607 个中心取得正常分支解，最大回环误差 1.00×10⁻⁹ px，根处 Jacobian 行列式范围 0.019498–1.048673，最小特征值下界 0.021878。对每个根 z，J(tz) 是 t 的六次对称矩阵多项式；代码检查 [0,1] 上七个 Bernstein 系数矩阵均正定，从而验证根沿此线段可连到光轴。数值舍入采用双精度。

| 边界 | 找到且验证中央根的整数坐标（含端点） |
|---|---|
| 顶行 y=0 | x=0…639 |
| 底行 y=479 | x=17…613 |
| 左列 x=0 | y=0…459 |
| 右列 x=639 | y=0…447 |

其余 593 个中心还做了解析排除，不以 Newton 失败定性。旧分析给出的中央理想半径上界 R=0.921405379；接收半径上界 0.820528592 单独排除 416 个。为核查其余点，取接收单位方向 n，理想坐标 r u，方向夹角 θ，切向参数向量 p=(p2,p1) 在 n 及其垂线上的分量记为 a、b。正向映射在 n 上的投影等于

    ρ(r) cosθ + r² [a + 2a cos²θ + 2b cosθ sinθ]。

由 1−cosθ ≥ sin²θ/2，并对 |sinθ| 配方，可得方向上界。令 m 为 [0,R] 上 ρ(r)/r 的保守下界；本模型 m/2−2R‖p‖ 为正。上界取

    max(ρ(r) + 3a r², 0≤r≤R) + R³ b² / (m/2−2R‖p‖)。

代码把半径分为 1024 段，每段对 ρ 检查端点和所有内部驻点，对 3a r² 单独取段上最大值再相加。全部 593 个中心的接收半径都超过各自方向上界，最小超量 4.87×10⁻⁵（归一化），大于计算留量 10⁻¹⁰。两下角均包含在内。逐行缺失区间保存在 JSON 中。

反方向用相同 K 的理想整数格投影并回求，307,200 个理想中心全部回环，最大 2.52×10⁻⁹ px；其中 4,804 个正向落点越过接收图边界。理想格正向 Jacobian 行列式为 0.365398–1.048673；公式与 OpenCV projectPoints 的最大差 2.55×10⁻¹³ px。两个方向在不同格上取样，不能用这一侧全通过覆盖接收底角失败。通过区域表示模型有数学逆解；训练点实际只到 y=310.564，板原点只覆盖 0.553–0.724 m。未据此生成图像、ROI 配置、CameraInfo 或深度反投影配置。[全帧数字与边界](frame_baseline.json)
